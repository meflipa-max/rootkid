# PizzaMaster

Gioco mobile-first per memorizzare le ricette della pizzeria (hamburger, insalatone, focacce, pizze dolci, friggitoria).

- **Allenamento smart**: 10 domande che danno più spazio ai piatti in cui sbagli (ripetizione dilazionata a scatole di Leitner).
- **Rush 60s**: quiz a tempo con combo e punteggio record.
- **Studia**: schede da girare, con autovalutazione.
- **Statistiche**: padronanza per piatto e categoria, ingredienti dimenticati più spesso, ripasso punti deboli.
- **Impostazioni**: modifica/aggiungi/elimina ricette, suoni, vibrazione, obiettivo giornaliero, backup JSON.

Dati salvati in `localStorage`. Le ricette di partenza sono in `src/lib/data.ts`.

```
npm install
npm run dev
npm run build
```
